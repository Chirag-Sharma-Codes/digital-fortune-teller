# 🔮 Digital Fortune Teller

A console-based fortune-telling game built with C++.

Choose a color, follow the number-selection steps, and discover your fortune!

## ✨ Features

- Color-based selection
- Interactive number choices
- Input validation for invalid entries
- Eight unique fortune messages
- Modular code using reusable functions

## 🛠️ Built With

- C++
- Standard Input/Output (`cin`, `cout`)
- Conditional Statements
- Loops
- Functions
- Switch Statements

## 🚀 How to Run

### Requirements

A C++ compiler, such as GCC (g++).

### Compile

```bash
g++ Fortune_Teller_V1.cpp -o FortuneTeller
Windows:
.\FortuneTeller.exe
Linux/macOS:
./FortuneTeller
